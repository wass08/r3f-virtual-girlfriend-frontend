# 🎭 Virtual Girlfriend - User-Controlled App

**Live Demo**: https://chitimalli.github.io/virtual-girlfriend/

![Video Thumbnail](https://img.youtube.com/vi/EzzcEL_1o9o/maxresdefault.jpg)

[Original Video Tutorial](https://youtu.be/EzzcEL_1o9o)

## 🎯 What This Is

A completely **user-controlled** 3D virtual girlfriend with:
- ✅ **3D Avatar** with facial expressions and animations
- ✅ **Real-time Voice** communication via WebRTC  
- ✅ **WebAudio Lip Sync** - avatar's mouth moves to your voice
- ✅ **AI Conversation** - chat with your virtual girlfriend
- ✅ **Zero Developer Costs** - all APIs provided by YOU

## 💰 Cost Structure

**For the Developer (me): $0** - This app costs me nothing to host or run!

**For You (the user):** You provide your own API credentials and control all costs:
- **GitHub Pages Hosting**: FREE
- **Agora Voice/Video**: FREE tier (10k minutes/month), then pay-as-you-use
- **ConvoAI**: Based on your usage plan
- **Total Control**: You decide what to pay and when to stop

## 🚀 How to Use

1. **Visit**: https://chitimalli.github.io/virtual-girlfriend/
2. **Click Settings** and enter your own API credentials:
   - Agora App ID & Token (for voice/video)
   - ConvoAI credentials (for AI conversation)
3. **Start chatting** with your virtual girlfriend!

## 🛡️ Privacy & Security

- ✅ **Your credentials stay with you** - never stored on any server
- ✅ **Client-side only** - everything runs in your browser
- ✅ **Open source** - you can verify the code
- ✅ **No tracking** - we don't collect any data

## 🛠️ Technical Features

- **React Three Fiber** - 3D rendering
- **WebRTC via Agora** - real-time voice communication
- **WebAudio API** - real-time lip sync analysis
- **Morph Target Animation** - facial expression control
- **SessionStorage** - secure credential management
